# Portfolio

My personal portfolio site: about me, experience, tech stack and featured projects.

Built with Next.js 15 (App Router), React 19, TypeScript and styled-components, using an
atomic design structure (`src/components/atoms`, `molecules`, `organisms`).

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm run start` | Serve the production build |
| `npm run lint` | ESLint |
